## Composition proof

`data/tokenized_dfm7` is exactly the DFM6 verified base (10,521) plus the 130
stripped additions from `data/tokenized_dfm7_jinja`; the 14
`dfm7_special_sources__*` tasks appear in the union with the wrapper prefix
stripped. Verified: expected == union, no base/addition collisions.

## Pipeline

`scripts/rebuild_dfm7.py` stages: `recover-lock`, `prepare` (staged download
replica, frozen scripts via git show, tokenizer semantic check, 33 input
digests), `convert` (frozen special-source converter with `--skip-kaenguruen`
plus a wrapper calling frozen `kaenguruen_training_row` over the pinned test
parquet, and the frozen Apertus sharder), `verify-rows` (byte-compare converted
outputs against `data/dfm7_special_sources`, shard row counts from the
historical manifest), `smoke`, `tokenize` (bounded historical chat driver,
64 workers), `assemble` (frozen union builder over the staged sapient
inventory), `verify` (all token/index arrays vs `data/tokenized_dfm7`).

Sampling: `epochs=6 seed=0 concat_workers=1` over the union; queue comparison
expects six epochs (the preserved sample is the documented six-epoch
extension; epochs 0-4 are unchanged by the canonical five-epoch build). See
[six-epoch sample](six-epoch-dfm7-sample.md).

Queue wiring: `enable-dfm7` installs recipe `dfm7-hf-v1` with stages
prepare, convert, verify-rows, smoke, tokenize, assemble, verify, sample,
compare; the sample stage is gated on `dfm7/all-token-comparison.json` and the
frozen prefix config. Kaenguruen wrapper equality against all 106 historical
rows is regression-tested.

Status 2026-11-02: lock recovered and recipe implemented with focused tests
passing. Two run failures were diagnosed and fixed in-recipe: (1) dolci
tool-call arguments use Python-literal SET literals whose `json_safe()` order
depends on `PYTHONHASHSEED` — the historical conversion ran with hash seed 2,
now pinned as `CONVERSION_HASH_SEED='2'` and applied to every frozen converter
subprocess; `compare_jsonl` also had to split on `'\n'` only because dolci
output contains raw U+2028/U+2029 inside JSON strings. (2) the adapter re-pin
above. prepare/convert/verify-rows have completed with all outputs
byte-matching the preserved build; smoke passed all ten source families after
the re-pin; tokenize/assemble/verify/sample/compare are running. No final
equivalence is claimed until `dfm7/verified.json` exists.
