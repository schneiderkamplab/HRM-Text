
# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/).

## [v1.0.1] - 2026-09-07

### Added

Nineteen Dutch collections from the [GPT-NL Public Corpus](https://huggingface.co/datasets/GPT-NL/GPT-NL_Public_Corpus),
each with its propella-1-4b annotations: `openraadsinformatie`, `woogle`,
`officiele_bekendmakingen`, `koninklijke_bibliotheek`, `nationaal_archief`,
`de_rechtspraak`, `tweede_kamer`, `belgian_journal`,
`dienst_publiek_en_communicatie`, `wikiwijs`, `c5_filtered`, `dans_knaw`,
`eurlex`, `zeeuws_archief`, `utrechts_archief`, `noord_hollands_archief`,
`naturalis`, `european_parliament`, `pbl`.
