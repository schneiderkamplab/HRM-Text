# Dynaword Annotations

This dataset contains annotations for
[Danish Dynaword](https://huggingface.co/datasets/danish-foundation-models/danish-dynaword).
The annotations were generated with
[ellamind/propella-1-4b](https://huggingface.co/ellamind/propella-1-4b). Each annotations row correponsds to the row in original Dynaword

Annotations contain fields like content type, quality, safety,
audience level, PII presence, and regional relevance.
